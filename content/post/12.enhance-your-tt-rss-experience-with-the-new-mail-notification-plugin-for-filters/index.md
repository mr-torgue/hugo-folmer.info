# Getting Started
Getting started with the Mail Notification Plugin for Filters is simple.
Make sure that your server can send email and install the mailer-smtp plugin.
All the instructions for installation are on my [GitHub repository](https://github.com/mr-torgue/ttrss-mail-filter).

Using it is simple: go to the preferences menu, click the filters tab.
Specify any filter you are interested in and select the Mail_Filter as an action.
Congrats, every time this filter is triggered you will get an alert!
